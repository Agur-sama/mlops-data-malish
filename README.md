# Практические работы MLOps №3–4

В этом репозитории собраны две последовательные практики. В третьей я работал с версиями данных Iris и Wine через Git, DVC и ClearML. В четвёртой использовал подготовленный Wine Dataset, сравнил шесть моделей с помощью MLflow и опубликовал выбранную модель в ClearML.

## Практика №3 — версии данных

Исходный код и DVC-файлы находятся в корне репозитория. Результаты и идентификаторы датасетов приведены в [отчёте практики №3](REPORT.md).

## Практика №4 — сравнение экспериментов

Вся информация по четвёртой практике собрана в одном документе — [`practice_4_wine/README.md`](practice_4_wine/README.md). Там есть порядок запуска, таблица всех шести экспериментов, метрики, ссылки на ClearML и пояснения для защиты.

Кратко о результате: лучший вариант — Random Forest (10 деревьев, глубина 3, минимум 3 объекта в листе). Его weighted F1 составил **0.972263 на validation** и **0.972474 на test**.

Отдельно можно открыть [таблицу сравнения](practice_4_wine/artifacts/comparison.csv) и [ClearML Task с опубликованной моделью](https://app.clear.ml/projects/9e2b5232e1df4f90aec6c7754396d8dc/experiments/902c3e4ad01f400986abecc0d772c78f/output/log).

### Быстрый просмотр результатов практики №4

Из корня репозитория:

```bash
cd practice_4_wine
poetry install --with test --no-root
poetry run pytest -q
poetry run mlflow ui --backend-store-uri ./mlruns --host 127.0.0.1 --port 5000
```

После запуска MLflow откройте <http://127.0.0.1:5000>. Если порт 5000 уже занят другим сервером, можно заменить его на 5001 и открыть соответствующий адрес.
